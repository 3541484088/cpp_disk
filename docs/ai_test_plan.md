# AI 智能助手功能测试文档

## 测试环境准备

- 确保已配置 API Key（DashScope / Ollama / Claude）
- 启动 `xms_disk_client_gui.exe`
- 点击 AI 面板右上角「设置」按钮配置 API

---

## 已知限制

1. `search_all_dirs` 只能搜索当前目录和一层子目录（`GetDirFiles` 对非当前目录返回空）
2. `index_file_content` 需要手动提供本地文件路径，暂无自动索引
3. 图片描述索引需要用户手动告诉 AI 图片内容，暂未接入多模态视觉模型自动分析
4. API Key 明文存储在本地 QSettings 中
